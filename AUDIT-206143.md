## Findings by owner
- **Titleblock lines (c3-sheets / c1-detail):** line colour/weight of the titleblock family lines: Revit draws black at 1 px (at 3000 px width), ours light grey hairlines (revision grid, project field rows, scale row). Likely pen colour/weight from the line style / object style of the titleblock lines not applied (looks like a default thin grey). Header-row separator of the revision table missing. Outer frame: Revit single black frame, ours double grey frame.
- **Titleblock text baseline (c3-annot):** every titleblock text sits 4-10 px lower (0.4-1 mm on the paper) than Revit's; 'A - 00' is ~35 px lower (about 3 mm) so it collides with the Scale row line. Looks like the label alignment/vertical anchor (top/middle/bottom) for large text. qa-view text-baseline check will give mm once a sheet PDF exists (none exported for this sheet: we only have the PNG): please let c3-writer export a PDF of 206143 so fonts/baseline/line weights can be measured numerically.
- **Value text margin:** right-aligned parameter values run flush to the cell frame (Revit keeps ~1 mm margin).
- **3D viewport 1 (c3-sheets + c3-viewer shading + c3-geometry materials):** Revit is a realistic render: textured brick and stucco walls, green metal roof, 3D red 'Pharmacy' lettering, sky and light grey ground; ours has flat colours, blank dark-red sign, green ground, no sky.
- **3D viewport 2:** Revit shaded white model on sky-blue; ours hidden-line wireframe.
- **Site plan (c3-sheets + c3-geometry):** white paving/plaza and drives, parking stripes, car symbol and tree symbols missing/different; ours fills the site grey/green.
